Porpoise for Windows (test build)
=================================

Porpoise is a GameCube and Wii emulator powered by Dolphin, with its own
controller-first launcher. This is an early test of the Windows version.

Requirements
- Windows 10 or 11, 64-bit
- A graphics card with Vulkan and an up-to-date driver
- A controller is best (DualSense, DualShock 4, Xbox, Switch Pro...); a
  keyboard works too

Getting started
1. Unzip this folder anywhere (it keeps everything inside it).
2. Put your own game backups in data\games, or add any folder in
   Settings > Games > Add a game folder.
3. Run Porpoise.exe.

Porpoise includes no games, BIOS or firmware. Play only games you own, from
backups you made yourself.

Keys
  F11 or Alt+Enter   full screen
  Arrows             D-pad              WASD    left stick
  Enter              Cross (confirm)    IJKL    right stick
  Backspace          Circle (back)      Space   Square
  Tab                Triangle           Q / E   L1 / R1
  1 / 3              L2 / R2            F1      Options
  F2                 touch pad          Esc     back / in-game menu

In a game, Options + touch pad (Start + View/Back on an Xbox controller)
opens the in-game menu.

Where things are
  data\        your games folder, covers, saves, settings
  trace.txt    what Porpoise did, for bug reports
  porpoise\core.log   the emulator's own log
